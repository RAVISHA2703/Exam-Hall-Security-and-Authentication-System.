# Exam-Hall-Security-and-Authentication-System.
 Main features: Register student examination details. Authenticate students using their roll number and exam registration details. Verify whether a student is assigned to the exam. Check exam hall and seat allocation. Prevent duplicate entry records. Record successful and rejected authentication attempts. Display student verification.
The program follows this sequence:
Register Student — Save the student's name, roll number, exam code, hall, and seat.
Authenticate Student — Check the roll number and exam registration code.
Verify Eligibility — Check whether the student is eligible and has already entered.
Confirm Documents — The invigilator manually checks the official admit card and photo ID.
Record Entry — Save the successful entry and timestamp.
Check Hall Status — Display assigned candidates and recorded entries.
View Entry Log — Review accepted, rejected, and pending attempts.
